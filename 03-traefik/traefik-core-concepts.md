# Traefik Core Concepts

## Entrypoints

Public listening ports such as `web` on `:80` and `websecure` on `:443`.

## Routers

Rules that match requests, usually by hostname.

## Middlewares

Reusable request processing such as redirects, auth, headers, and rate limits.

## Providers

Sources of configuration, such as Docker labels and file-based dynamic config.
